# Part Framework Template

Before writing any Part (部) of a novel, build a framework document first.
Do NOT start writing chapters until the framework is discussed and approved.

The framework is what makes chapters flow smoothly. Book 01's Part 3 was written
faster and with fewer revisions than Parts 1–2 because the framework was locked
before the first word was written.

---

## Framework Document Structure

Save as: `调研材料/XX-第N部框架.md`

### 1. Part Mission (任务)

3 bullet points maximum. What does this part accomplish for the whole book?

- What gap in the story does it fill?
- What emotional state does it leave the reader in?
- What must be true at the end of this part that wasn't true at the beginning?

### 2. Character Relationship Tree (人物关系树)

For the POV character, map every significant relationship:

```
POV CHARACTER
│
├── 【Family / 家庭】
│   └── Person A
│       └── Relationship: one sentence describing the dynamic
│       └── 认知弧线 (perception arc): how POV's understanding of this person
│           changes across the part — label each stage
│       └── Story nodes: list the 4–8 specific moments that mark the arc
│
├── 【Emotional / 情感】
│   └── Person B
│       └── Number of scenes: set a cap (e.g., "4 scenes max")
│       └── Each scene: year, location, one-sentence summary
│
└── 【Mirror characters / 镜像人物】
    └── Person C
        └── Mirror function: what question does this person illuminate?
        └── Story nodes: when they appear and what they reveal
```

**Key principle**: Every character must have a clear function. If you can't answer
"what does this character illuminate about the protagonist?", cut them.

### 3. Six Mirror Matrix (六面镜子)

**什么是六面镜子：** 每个配角都是主角的一面镜子——他/她的存在，照出主角自己看不见、说不清楚的某个问题。镜子不解释答案，只提出问题。主角和每面镜子的关系，就是读者理解主角内心的一条通道。这是本项目自创的工作术语，对应叙事学中"功能性人物"（functional characters）的概念，但更强调每个人物只做一件事：照出一个问题。

| Mirror type | Character | Question it illuminates                       |
| ----------- | --------- | --------------------------------------------- |
| [type]      | [name]    | [one specific question about the protagonist] |

Aim for 4–6 mirrors. Each should illuminate a different dimension of the protagonist.
Avoid mirrors that ask the same question.

### 4. Group Portrait Plan (群像规划)

Number and pre-plan every group scene (群像①②③…):

| #   | Scene | Time | Location | Social positions represented | Function     |
| --- | ----- | ---- | -------- | ---------------------------- | ------------ |
| ①   | name  | year | place    | 3–5 distinct voices          | what it does |

Rules:

- Distribute group scenes across chapters — don't cluster them
- Each group scene must represent real social positions, not just personality contrasts
- The protagonist observes; she does not lead or summarize the group
- Plan the group scenes before writing any chapter

### 5. Chapter Map (章节划分)

For each chapter:

```
### Chapter N: [Title]
**Time**: year/period, location
**Content**: bullet list of scenes
**Function**: what this chapter DOES for the story (not just what happens in it)
```

The **Function** line is mandatory. Examples:

- "Establishes X; introduces Y as mirror; plants Z for payoff in Ch.6"
- "First time reader sees A through B's eyes; closes the loop opened in Part 1 Ch.3"

### 6. Key Writing Decisions (关键写作决定)

Lock these in before writing. Tag each as: 【已定】or 【待讨论】

Common decisions to lock:

- What does the central letter/object/scene actually contain?
- What is the final image of the part/book?
- Where does the most important confrontation happen, and what is said?
- Which scenes are deliberately withheld (reader infers, never shown)?

Do NOT begin writing until all 【待讨论】items are resolved with collaborator.

---

## Framework Review Checklist

Before approving a framework:

- [ ] Every character has a named mirror function
- [ ] Group scenes are numbered and distributed across chapters
- [ ] Every chapter has a Function line (not just content)
- [ ] Key writing decisions are marked 【已定】
- [ ] Timeline is consistent with all other parts and character birth years
- [ ] No chapter does only one thing (advance plot OR reveal character — must do both)
- [ ] The part's opening and closing states are clearly different

---

## How Long Should Framework Discussion Take?

Expect 2–4 rounds of revision before locking. Common revision triggers:

- A character's arc is flat (same understanding at start and end)
- Two mirror characters ask the same question
- A chapter's Function is "and then X happens" (no structural purpose)
- A key writing decision was assumed, not discussed

The framework discussion is not overhead — it IS the writing. Chapters written
without a locked framework will require structural rewrites.
